必要な画面は **「写真を見る」「写真を投稿する」の2つ**です。現在のリーンキャンバスに合わせて、言葉と解説は生成AIが返す構成にします。

「① 誰の」に投稿専用の担当者は指定されていないため、唯さんが見る・投稿する両方を試せる流れにします。

**たどる順番：写真を見る → 写真を投稿する → 投稿した写真を見る**

**① 写真を見る画面（主画面）**

目的：平泉の写真から、行ってみたい場所を見つける。

上から順に：

1. **見出し**：「平泉の細道」
2. **説明文**：「写真から、行ってみたい平泉を見つけよう」
3. **ボタン**：「写真を投稿する」→ ②へ
4. **写真一覧**：各投稿に「写真 → 場所タグ → 言葉 → 解説」の順で表示  
   文字の例：「毛越寺」「写真に添える言葉：〇〇」「言葉の解説：〇〇」

最初から写真を見られるよう、見本の投稿を用意します。AIの文章には「AIによる生成」と表示します。

**② 写真を投稿する画面**

目的：自分が訪れた場所の写真を共有する。

上から順に：

1. **見出し**：「平泉の一枚を投稿」
2. **画像選択欄**：「写真を選ぶ」
3. **選んだ写真のプレビュー**
4. **場所の選択欄**：「撮影した場所」  
   選択肢：「中尊寺／毛越寺／その他」
5. **説明文**：「投稿すると、AIが写真に添える言葉と解説を作ります」
6. **ボタン**：「投稿する」→ 保存して①へ
7. **戻るリンク**：「投稿せずに戻る」→ ①へ

投稿後は①の先頭に新しい写真と「投稿しました」を表示します。言葉の生成中は「言葉を作成中」、失敗した場合は「言葉を作れませんでした」と「再試行」ボタンを写真の下に表示し、写真自体は見られるようにします。

確認画面・完了画面・写真詳細画面は省きます。

**最初にさわる主画面は①「写真を見る画面」。写真を見たあと、最初に押してもらうボタンは「写真を投稿する」です。**
